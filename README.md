# Industrial OT Network & Agent Monitoring System (IONM-System)

## 📌 项目简介 (Project Overview)
本项目是一套专为**工业控制网络（OT）**、**现场工控机（Windows）**以及**自动化线体网络安全**设计的分布式监控与告警感知系统。

系统采用分布式三层架构，支持海量现场 Agent 的高并发接入，具备强大的工业网络协议感知（如 PROFINET DCP 扫描）与 10+ 种工控主动/被动网络安全及状态监控能力。

### 💡 核心技术亮点
1. **多网卡与工业网络感知**：针对工控机双网卡环境（分别连接企业 IT 网与线体 PLC OT 网），Agent 支持网卡接口绑定，直接执行 **PROFINET DCP 扫描**，精准绘制线体设备拓扑。
2. **工业级安全通信**：Agent 与 Master 之间采用**私有 TCP 协议**，基于 **HMAC 身份认证机制**与**动态密钥对称加密**，严防工业现场指令被劫持或重放攻击。
3. **高并发与跨平台**：Master 核心采用 C++ 编写，全面兼容 Windows (MSYS2 环境编译) 与 Linux (Ubuntu 22.04 LTS LTS)，无缝支持异构系统部署。
4. **边缘边缘告警收敛引擎**：Master 内部集成了智能告警精炼算法。针对高频重复告警采用“指纹识别 + 滑动窗口去重”机制，成功实现**告警信息数千倍级收敛**，避免 Zabbix 刷屏与日志撑爆，同时确保关键告警不丢失。

### 2. 现场工控机 10+ 种智能告警矩阵
系统在现场 Agent 实现了高密度的监控矩阵，一旦触发，将通过 Master 智能收敛引擎精炼后推送到 GUI 平台：

| 监控维度 | 告警项 | 核心逻辑与报文内容说明 |
| :--- | :--- | :--- |
| **主机性能监控** | CPU / 内存 / 存储利用率 | 秒级轮询，精准上报 C盘/D盘 爆满及硬件瓶颈 |
| **合规与进程安全** | 软件合规 / 系统进程检查 | 实时感知合规软件 A/B/C 异常卸载或核心进程退出 |
| **网络链路质量** | ARP RTT / ICMP RTT 探测 | 监测工控机到关键线体节点的网络延时与丢包率 |
| **主动网络感知** | TCP 端口可达性检查 | 实时感知关键工业网关或服务端口的开放与连通性 |
| **被动网络防御** | 厂商OUI / 新设备 / 广播监控| 实时感知线体网络内 PPS 广播风暴及未知资产接入 |
